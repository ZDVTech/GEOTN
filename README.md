# Geo-TN / Drill Monitor — Сценарий, раскадровка и 14-дневный план производства (V4.0)

Сценарий, раскадровка и календарный план создания 5-минутного ролика о компании «ГеоТехНавигация» и экосистеме Drill Monitor.

- **Хронометраж:** 05:00 (300 секунд), 14 сцен.
  - **Часть I (00:00–02:00, Сцены 01–06, Дни 1–8):** Представление компании «ГеоТехНавигация», производственная база, подготовка китбоксов и корзин, логистика, двухсекционная телесистема, забойные измерения и гидравлический канал связи.
  - **Часть II (02:00–05:00, Сцены 07–14, Дни 9–14):** ПО «Drill Monitor», масштабирование (множество буровых → Единый Контрольный Центр), сбор и каталогизация данных на центральном сервере, работа локального настроенного ИИ (ранние предупреждения и сбор статистики), предиктивный анализ проблем на основе реальной статистики и глобальная модель — полное управление бурением и построением скважины через ИИ-модель под контролем опытного DD-инженера.
- **Срок создания видеоклипов:** 14 календарных дней (посценный график внутри страницы и карточек).
- **Интерактивная работа (review.js):**
  - В каждой сцене можно редактировать и сохранять текст диктора («Сохранить текст диктора») и оставлять заметки («Сохранить заметку»).
  - Все сохранения записываются в облачную БД D1 (`drill-monitor-storyboard`) и синхронизируются между всеми участниками по ссылке без пароля и регистрации.
